현재 세션의 작업 내용을 노션 "개발 로그" 하위 오늘 날짜 페이지에 기록한다.

## 절차

### 1. 작업 내용 파악

현재 세션 대화를 돌아보며 아래 항목을 정리한다:

- **작업**: 완료하거나 진행한 것
- **결정**: 선택한 방향과 이유 (왜 그 방향을 택했는지가 핵심)
- **막힌 것**: 문제 상황과 해결 방법 (미해결이면 미해결로 기록)
- **다음**: 이어서 할 것

### 2. git log 확인

```bash
git log --since=midnight --oneline
```

커밋이 있으면 작업 항목에 포함한다. 커밋이 없어도 대화 맥락만으로 기록한다.

### 3. 노션 오늘 날짜 페이지 확인

1. notion-search로 오늘 날짜(YYYY-MM-DD) 제목의 페이지 검색
2. 없으면 "개발 로그" 하위에 새 페이지 생성
3. 있으면 기존 내용 fetch 후 내용 추가 (덮어쓰지 않는다 — 같은 날 여러 번 호출 가능)

"개발 로그" 페이지를 찾지 못하면 notion-search로 "개발 로그" 검색해서 부모 페이지 ID를 확인한다.

### 4. 기록 형식

```
## 작업
- 완료하거나 진행한 것

## 결정
- 선택한 방향과 이유

## 막힌 것
- 문제 + 해결 방법 또는 (미해결)

## 다음
- 이어서 할 것
```

항목이 없는 섹션은 생략한다. 결정 항목은 "왜"가 없으면 의미 없으니 이유를 반드시 포함한다.
